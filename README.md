# Hotel Website

## About the Project

This project is a modern and sophisticated hotel website designed to provide visitors with an easy and enjoyable browsing experience. 
It showcases the hotel's food and beverage offerings, and other relevant information through a clean and user-friendly interface.

The website is built using HTML, CSS, and JavaScript, with a focus on responsive design, functionality, and visual appeal.

## Features

- **Homepage:** Introduces the hotel and provides easy navigation.
- **Menu Page:** Displays different food and beverage categories.
- **product Pages:** Dynamically displays products based on the selected category.
- **Navigation:** Allows users to move easily between different sections of the website.
- **Responsive Design:** Designed to provide a good browsing experience across different screen sizes.

## Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and layout.
- JavaScript – Functionality and dynamic content.
